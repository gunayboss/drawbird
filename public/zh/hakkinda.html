关于 DrawBird

DrawBird 是个小小的画画游戏。你画一只鸟，给它起个名字，说一声“放飞！”。几秒钟后，你的鸟就和来自世界各地的鸟一起，在同一片天空里扇动翅膀了。

为什么做它？

我想要一个不用画得多好、也没人追着分数跑的地方。只管做点东西，分享出去，享受就行。

选鸟的原因很简单。谁都能画一只鸟，每个孩子都见过鸟，而且鸟会飞。自己画的东西活过来飞走，是一种很小但很真实的快乐。

除了游戏，我也很在意让大家认识鸟。在土耳其的鸟页面里，我讲你在阳台上能看到的鸟；在画画教程里，我一步一步教你怎么画它们。

我的原则

  • 免费，不用注册。我不要邮箱、密码和真名。
  • 适合各个年龄。新鸟每天都有人看，不当的名字会被拦截，每只鸟都能被举报。
  • 数据很少。我只保留游戏运行必需的数据。没有 Cookie，没有跟踪工具。
  • 开源。全部代码都在 GitHub 上，采用 AGPL-3.0 许可证。

灵感

点子来自 Alden Hallak 的画鱼游戏 DrawAFish。DrawBird 的代码是从零写的。没有用 DrawAFish 的代码、图片或模型。

谁在做？

DrawBird 是我在土耳其以独立开发者的身份做的。有建议、发现 bug 或者想合作，可以在 GitHub 上给我留言。
